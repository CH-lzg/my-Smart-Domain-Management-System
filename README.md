# 智域管家 - 智慧园区管理系统
毕业设计项目，前端网页端

## 项目简介
本系统为智域管家系统，实现家庭信息展示，设备管理，数据可视化等功能。采用纯前端网页技术开发，页面直观易用，满足家庭日常管理业务需求。

## 技术栈
- HTML
- CSS
- JavaScript

## 目录结构
├── assets     # 静态资源（图片、图标等）
├── css        # 样式文件
├── html       # 页面html文件
├── js         # js逻辑脚本

## 运行方式
1. 将项目源码下载到本地
2. 直接打开 html 目录下的首页文件即可运行，无需后端环境

## 项目说明
本项目为智能软件工程课程设计作品，实现家庭信息可视化管理界面。
